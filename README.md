# ERIC BOOKS

Maquette initiale responsive de la librairie numérique ERIC BOOKS.

## Mise en ligne
Le fichier `index.html` est une première interface statique. Il peut être publié avec GitHub Pages ou un hébergeur statique.

## Important
Les boutons Acheter sont volontairement des démonstrations : aucun paiement n'est encaissé et aucun PDF n'est délivré. Avant d'activer les ventes, il faudra connecter Wave Checkout côté serveur, vérifier les notifications de paiement, enregistrer les commandes et délivrer les fichiers via des liens privés temporaires. Ne placez jamais de clé secrète Wave dans `index.html`.

Les romans, couvertures, résumés, prix et extraits de la maquette sont des exemples à remplacer.
